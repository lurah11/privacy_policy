Install a missing font for PDF text editing

If AZ Pdf Toolkit says a PDF font is missing, the PDF may contain only a limited embedded copy. Install the full font on Windows to edit with more characters and keep the intended appearance.

  1. Note the font name

    Click the text box in Edit text. The warning below the text controls names the original font. Write down that name exactly.

  2. Get the font from a trusted, licensed source

    Use the font supplied with the document, your organization, or the typeface publisher. Ask the document creator if you do not have it. The limited subset embedded in a PDF is not a full Windows font.

  3. Install it in Windows

    For a .ttf or .otf file, right-click the file and choose Install. You can also choose Install for all users if you have permission. To check the result, open Settings → Personalization → Fonts and search for the font name.

  4. Reopen the PDF and edit again

    Close and reopen AZ Pdf Toolkit, then open the original PDF and click the text box. The warning should be gone. Make your edit and use Save PDF as to create a new copy.

Can't get the original font?

Choose an installed font in the Text box controls and inspect the result before saving. For characters already present in the PDF's embedded subset, AZ Pdf Toolkit may be able to reuse that subset.
